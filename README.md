# ninjaplzzzz-deploy-web

Built output for **ninjaplzzzz.com**. Every file here is generated by the
CI pipeline in `VectaShield/Main-NinjaPlzzzz-Website` and force-overwritten
on each deploy. **Do not edit anything here by hand: your change will be
wiped on the next push to the source repo.**

Hostinger pulls the root of this repository straight into `public_html` via
a push webhook.
